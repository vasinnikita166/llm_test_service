# LLM Service

Это FastAPI-приложение предоставляет интерфейс к языковой модели.

## Запуск приложения

### 1. Установка зависимостей

Убедитесь, что у вас установлен Python (рекомендуется версия 3.9 или выше). Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
# Активация (Windows):
venv\Scripts\activate
# Активация (Linux/macOS):
# source venv/bin/activate

pip install -r requirements.txt
```

### 2. Запуск сервера

Запустите сервер с помощью Uvicorn:

```bash
python main.py
```

Или используйте Uvicorn напрямую:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Параметр `--reload` включает автоматическую перезагрузку сервера при изменении кода (удобно для разработки).

### 3. Проверка работы

После запуска приложение будет доступно по адресу:

- **API:** `http://localhost:8000`
- **Документация (Swagger UI):** `http://localhost:8000/docs`
- **Альтернативная документация (ReDoc):** `http://localhost:8000/redoc`

### 4. Остановка приложения

Для остановки сервера нажмите `Ctrl+C` в терминале, где он запущен.
